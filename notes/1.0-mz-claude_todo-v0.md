Act-PRM pipeline. Everything below is in the repo `act-prm-blog`, branch
`act-prm-pytorch` (`github.com/mzio/act-prm-blog`).

## What this project is
Act-PRM = infer latent **thoughts** behind logged, action-only agent demos via an
offline **EM**: sample G candidate thoughts `z` for each logged action `x` in state
`s`, reward by the length-penalized action likelihood `p(x|s,z)`, group-normalize to
advantages, PG/EM step on the `(thought+action)` tokens. PyTorch/LoRA stack is a lean
fork of `strl`. `p(x|s,z)` can be scored by the **current policy** (`--no-score_with_base`)
or the **frozen LoRA-detached base** (`--score_with_base`).

## Stage 1 — thought generation (do this now, 2 GPUs)
```bash
CUDA_VISIBLE_DEVICES=0 ./scripts/train.sh --env_config act_prm/tau2_airline \
  --generator_config act_prm --trainer_config pg --model_config hf_qwen3_4b_instruct \
  --lora_config r8_a16_linear --replay_buffer_config default --no-score_with_base \
  --group_size 4 --batch_size 4 --num_batches 25 --eval_every 5 --no_initial_eval \
  --length_penalty 0.15 --verbose > /tmp/airline_policy.log 2>&1 &
sleep 60   # stagger model loads (oomd risk under swap pressure)
CUDA_VISIBLE_DEVICES=1 ./scripts/train.sh --env_config act_prm/tau2_airline \
  ... --score_with_base ... > /tmp/airline_base.log 2>&1 &
```
Each infers a thought/step (`best p(x|s,z)=…`), M-step runs (`n_skipped_seq_len: 0`),
saves every group to `<log_path>/generations.jsonl`. Uncapped peaks ~72 GB/GPU. For a
generate-only relabel pass add `--no_train`. To cover ALL non-rl_eval tasks, rebuild
the split with `--eval_frac 0` (see `scripts/make_split.py`).

## Stage 2 — SFT with hide-observations (after Stage 1)
`./scripts/train_sft.sh <env> <variant>` — variants: `actions_only` (expert baseline),
`thoughts_policy`, `thoughts_base`. Uses `SFTTrainer` + `advantage_mode best` +
`--hide_observations` (context = system + first user + last obs + all model msgs).
```bash
CUDA_VISIBLE_DEVICES=0 ./scripts/train_sft.sh act_prm/tau2_airline actions_only &
CUDA_VISIBLE_DEVICES=1 ./scripts/train_sft.sh act_prm/tau2_airline thoughts_base &
# then thoughts_policy on a free GPU
```

## Stage 3 — RL from the SFT checkpoint
`./scripts/train_rl_from_sft.sh <airline|retail> <sft_ckpt_dir>` — warm-starts the SFT
LoRA (`--resume_from`) and RLs on the tau2-gym env (Claude user-sim via claude_agent_sdk;
ambient Claude Code OAuth, else `CLAUDE_CODE_OAUTH_TOKEN` in `.env`). Needs `.venv-tau2`
(`UV_PROJECT_ENVIRONMENT=.venv-tau2 uv sync --extra tau2`) + a local tau2-bench clone.

## Ops
- Kill a run: `pkill -f '[m]ain_pytorch'` (bracket avoids self-match).
- Back up code: `./scripts/snapshot.sh "msg"` (commits + refreshes the dotsynced bundle
  at `~/.claude/act-prm-backups/act-prm-blog.bundle`).
- If a run vanishes: `dmesg | grep oomd` — the box can SIGKILL under swap pressure;
  stagger launches / cap obs (`--obs_max_chars 3000`) or `--group_size 2` to fit two/GPU.
- Model/data caches are per-box (not dotsynced); splits + code come with the repo.
